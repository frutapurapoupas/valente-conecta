# VALENTE CONECTA

## Plataforma Inteligente para Cidades

O Valente Conecta é um sistema modular desenvolvido em Next.js + TypeScript + Supabase.

Sua arquitetura foi projetada para separar completamente:

Interface

↓

Lógica

↓

Persistência

↓

Banco de Dados

Cada módulo possui independência funcional.

Exemplos:

Academia

Cozinha

Comércio

Financeiro

Moto Táxi

PDV

Empregos

Serviços

Catálogo

IA

Dashboard

Todos seguem a mesma arquitetura.

Este projeto utiliza documentação viva.

Antes de qualquer alteração consulte a pasta:

docs

Toda IA deve seguir obrigatoriamente os documentos dessa pasta.

Não criar arquitetura nova.

Não criar padrões diferentes.

Sempre reutilizar código existente.

Sempre respeitar os componentes existentes.

Sempre atualizar documentação após alterações relevantes.
