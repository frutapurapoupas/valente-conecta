2. CAUSA PROVÁVEL:
   Os caracteres '�' aparecem quando o banco de dados SQLite 
   recebeu dados com encoding UTF-8 que foram corrompidos durante
   a inserção pelo PowerShell.

3. SOLUÇÕES:

   A) Correção manual (recomendado):
      Acesse http://localhost:3000/admin/cozinha/ingredientes
      Edite cada ingrediente com nome errado e corrija.

   B) Reset do banco de dados:
      npx prisma db push --force-reset
      Depois execute os scripts de população novamente.

   C) Script de correção via API:
      O script abaixo corrige os nomes diretamente.

4. SCRIPT DE CORREÇÃO RÁPIDA:
$correcoes = @{
    "A��car" = "Açúcar"
    "Chocolate em p�" = "Chocolate em pó"

$ingredientes = Invoke-RestMethod -Uri "http://localhost:3000/api/admin/ingredients" -Method GET

foreach ($ing in $ingredientes) {
    if ($correcoes.ContainsKey($ing.name)) {
        $body = @{ id = $ing.id; name = $correcoes[$ing.name] } | ConvertTo-Json

        Write-Host "Corrigido: $($ing.name) → $($correcoes[$ing.name])"
    }
}
